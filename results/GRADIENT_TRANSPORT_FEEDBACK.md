# Transport operator vs NMDA feedback — exact geometry-gradient decomposition

## Question

The real morphology gradient changes sign with drive, and those sign changes
recur across branches.

Which part of the architecture causes that?

This audit separates the exact metric tangent around the **same base nonlinear
trajectory** into two causal counterfactual pieces:

~~~text
FULL GEOMETRY TANGENT
        =
FROZEN-CURRENT TRANSPORT TANGENT
        +
VOLTAGE-DEPENDENT NMDA FEEDBACK TANGENT
~~~

The frozen-current arm changes geometry and differentiates the compiled passive
recurrence and geometry-dependent input map, but replays the exact synaptic
current waveform generated by the unperturbed nonlinear trajectory.

The feedback term is the additional sensitivity obtained when those currents
are again allowed to change with the local voltages they help create.

## The baseline pre-site length pocket is a nonlinear-feedback effect

The 1× branch map previously showed:

~~~text
full length tangent:
    positive      7 / 31
    negative     24 / 31
~~~

The frozen-current transport tangent at the same operating point is:

~~~text
transport-only length tangent:
    positive      0 / 31
    negative     31 / 31
~~~

All **seven** positive pre-site length directions are sign reversals introduced
by voltage-dependent feedback.

Therefore the earlier x≈0.25 sign structure should not be described as a
passive cable growth rule.

It is a property of the **coupled geometry × nonlinear-state system**.

## Relation to the original architecture question

The repo's useful abstraction is now more specific than "a neuron is a nonlinear
transfer function":

~~~text
morphology metric theta
       |
       v
transport operator T(theta)
       |
       +------------------------+
       |                        |
       v                        |
local voltage ------------------+
       |
       v
nonlinear current J(V)
       |
       v
soma / local outputs
~~~

Differentiating it gives two experimentally separable pieces:

~~~text
d output / d theta
    =
transport sensitivity
    +
state-dependent nonlinear feedback sensitivity
~~~

So morphology does not need to be called "the nonlinearity."

Morphology builds the transport operator. The local membrane nonlinearity can
then reshape — and sometimes reverse — the functional gradient of that
transport operator.

## Fence

The frozen-current arm is a causal sensitivity counterfactual, not a biological
neuron with NMDA removed. It replays the nonlinear base current waveform so the
transport contribution can be isolated around exactly the same trajectory.

This audit is still one branch in one cell. Cross-cell recurrence of this
decomposition remains open.
