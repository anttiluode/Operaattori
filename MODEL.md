# The reduced Operaattori model

The experiments have converged on a small explicit dynamical system.

It is not a new mathematical species. It is a conductance-based nonlinear
feedback circuit embedded in geometry-indexed Green/impulse operators. The
value of the repo is that this form was reached by causal decomposition and
held-out attacks on one released human-neuron reconstruction.

## State and operators

Let there be m material interaction sites on one compact dendritic branch.

Geometry (g) supplies three linear objects:

[
V_{0,g}(t) in mathbb R^m
]

the no-input local voltage trajectory,

[
G_g(t) in mathbb R^{m	imes m}
]

the local current-to-voltage Green/impulse operator, and

[
T_g(t) in mathbb R^{1	imes m}
]

the current-to-readout transport operator.

For Operaattori's current assays, (m=3) and the readout is somatic voltage.

## Input program

An event program produces two voltage-independent conductance programs per
site:

[
g_{A,i}(t)
]

for AMPA and

[
g_{N,i}^{raw}(t)
]

for the NMDA conductance before magnesium block.

In the current released model these kinetic templates are shared across the
tested sites. Timing is represented by causal shifts of the same templates.

## Local nonlinear law

The HUMAN magnesium block is

[
B_gamma(v)
=
rac{1}{1+exp(-gamma v)/3.57},
qquad
gamma = 0.078 {m mV}^{-1}.
]

With reversal potential (E=0) mV, positive-inward synaptic current is

[
J_i(t)
=
left[
g_{A,i}(t)
+
g_{N,i}^{raw}(t)B_gamma(v_i(t))
ight]
left[E-v_i(t)ight].
]

The local voltage is not prescribed. It is generated by the same currents
through the geometry-specific Green operator:

[
v_i(t)
=
V_{0,g,i}(t)
+
sum_j
left(G_{g,ij} * J_jight)(t).
]

Therefore (J) and (v) form a nonlinear feedback system.

Operaattori currently solves this fixed point by damped iteration. The
portable NumPy runtime uses damping 0.5 and relative current-update tolerance
(10^{-8}), matching the preregistered reduction audits.

## Readout

Once the local currents are solved,

[
y_g(t)
=
sum_j
left(T_{g,j} * J_jight)(t).
]

For the current experiments (y) is somatic depolarization.

## Computational graph

~~~text
geometry g
   |
   +----> local Green operator G_g ----+
   |                                   |
   +----> output transport T_g         |
   |                                   v
   +----> baseline V0_g          local voltage
                                      |
input events                           |
   |                                   v
   +--> AMPA / raw-NMDA kinetics --> synapse law
                                      |
                                      v
                                 local currents J
                                   |        ^
                                   |        |
                                   +---G_g--+
                                   |
                                   +---T_g------> output y
~~~

The loop through (G_g) is the local nonlinear computation. (T_g) is the
downstream transport/readout.

## What the receipts currently support

### Linear transport is extremely accurate

When supplied the actual held-out full-model synaptic currents,

~~~text
site currents -> measured T_g -> soma
~~~

reconstructs the released-model soma traces at roughly 0.4% median NRMSE.

### A frozen local current operator is partly portable

Measure the nonlinear current waveform in the original geometry, change branch
length, replace only (T_g):

~~~text
frozen soma trace                 9.82% median error
T_new[J_original]                 5.12%
T_new[J_actual] oracle            0.46%
~~~

This established the first transport/local-operator factorization.

### T_g is input-independent over the tested panel

The same measured transport operator was reused for middle-single, outer-pair
and triple input patterns:

~~~text
36 held-out cases
factorized median                 2.82%
transport oracle                  0.39%
factorized wins                   28 / 36
~~~

### Explicit feedback removes the waveform lookup

Replacing the stored nonlinear current with the explicit conductance law and
the measured (3	imes3) local Green operator produced:

~~~text
54 full-model cases
reduced current error             0.38%
reduced soma error                0.43%
transport oracle                  0.40%
~~~

### The same circuit generalizes in time

No new fit was added for asynchronous events:

~~~text
72 full-model cases
reduced current error             0.26%
reduced soma error                0.50%
transport oracle                  0.37%
~~~

Removing the local voltage-feedback loop while keeping conductances and
transport fixed gives 41.41% median soma error.

So the nonlinear feedback is not decorative.

## What geometry means here

The early Operaattori experiments separated two very different uses of
geometry.

Pure rigid re-embedding of the material cable leaves the intrinsic cable
operator invariant. Intrinsic metric change alters cable transport.

In the reduced model, that distinction appears cleanly:

~~~text
world embedding
    |
    +-- absent external world coupling --> not represented in intrinsic G/T

intrinsic metric / cable parameters
    |
    +------------------------------------> changes V0_g, G_g, T_g
~~~

A separate external-world interaction would enter as another geometry-dependent
drive or boundary term. It should not be smuggled into the intrinsic operator.

## Current validity envelope

The earned empirical claims are deliberately narrower than the equations:

- one pinned released human L2/3 cell-1125 model;
- six compact apical branch sections;
- three interaction sites per branch;
- HUMAN released AMPA/NMDA kinetics;
- subthreshold regime with no somatic spike-guard crossings;
- selected branch-length factors 0.80, 1.00 and 1.20 for the completed reduction
  assays;
- event multiplicity 8 per active site;
- synchronous and three preregistered asynchronous three-site timing programs;
- 0.025 ms simulation time step;
- 90 ms scored post-reference window.

The equations may apply more broadly. The receipts do not yet establish that.

## The remaining upstream problem

The current reduced circuit still receives geometry-specific (V_{0,g}),
(G_g) and (T_g).

The next active audit asks whether geometry can itself generate those operators:

[
g
longrightarrow
(V_{0,g},G_g,T_g)
longrightarrow
J
longrightarrow
y.
]

Specifically, operators measured only at branch-length factors 0.80 and 1.20
are being linearly interpolated to held-out 0.90, 1.00 and 1.10 targets.

## Cross-cell upstream map

The within-cell model used geometry-indexed operator packs. Cross-cell work
tested what must replace that scalar coordinate.

Two leave-one-cell-out scalar charts failed:

~~~text
gross morphology -> operator             0.3522 joint NRMSE
electrotonic/Rall chart                  0.4070
combined                                 0.3062
training-basis PCA oracle                0.0307
~~~

A direct morphology-graph cable construction then generated the matched-passive
operator without any cross-cell learning:

~~~text
24 cells
144 branch operator packs

median joint G/T NRMSE                   0.0021
median local G                           0.0013
median soma T                            0.0024
~~~

Therefore the empirically supported cross-cell passive map is not

~~~text
small morphology vector -> operator coordinates
~~~

but

~~~text
full loaded morphology graph
        |
        v
passive cable equations
        |
        v
G, T
~~~

The full nonlinear cross-cell model has **not** yet been established. The
successful AMPA/NMDA Green-circuit closure was earned on cell 1125 and its
within-cell metric perturbations. A separate audit is required before combining
graph-generated cross-cell G/T with that nonlinear law across the 24-cell panel.

See
[results/DIRECT_CABLE_GRAPH_AUDIT.md](results/DIRECT_CABLE_GRAPH_AUDIT.md).
