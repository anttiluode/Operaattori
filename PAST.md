# PAST — closed synthetic moving-operator line

Operaattori changed direction at Gate 10.

Gates 0–9 remain useful provenance for why matrices entered the project, but
they are not the current claim.

## Gates 0–4 — grown synthetic operator

The original substrate asked whether identical systems could convert signal
order into persistent morphology and whether that morphology changed later
propagation.

- [Gate 0](results/GATE0.md) — protocol and abstract rulers.
- [Gate 1](results/GATE1.md) — history survives in morphology after washout.
- [Gate 2](results/GATE2.md) — order effect clears same-history multistability.
- [Gate 3](results/GATE3.md) — frozen anatomy changes the future operator.
- [Gate 4](results/GATE4.md) — delayed scalar consequence only works when
  paired with the correct local eligibility address.

Important negative ruler: an abstract bistable state can also store the order.
Once frozen, the synthetic spatial dynamics are exactly replayable by the
derived matrix. This was never evidence for a new function class.

## Gates 5–9 — make the matrix itself move

These gates were the direct conceptual bridge to the matrix-exponential video.

- [Gate 5](results/GATE5.md) — a moving compact operator tracks a smoothly
  drifting memory kernel efficiently, but loses badly on exact addressable
  delay.
- [Gate 6](results/GATE6.md) — richer hidden operator family.
- [Gate 7](results/GATE7.md) — moving operator basis.
- [Gate 8](results/GATE8.md) — learned developmental/meta law.
- [Gate 9](results/GATE9.md) — continuous path through operator space / Lie
  generator framing.

The useful mathematical intuition was:

~~~text
dx/dt = A x
x(t) = exp(t A) x(0)
~~~

A generator gives a continuous flow.

But a synthetic moving matrix does not establish that biological 3-D movement
is itself computational.

## Gates 10–11 — bridge to the real scaffold

[Gate 10](results/GATE10.md) replaces the synthetic strip with the real human
cell-1125 morphology and encodes it exactly as parent-local 4x4 transforms.

[Gate 11](results/GATE11.md) attaches classical cable matrices and shows that
heterogeneous serial operators can be order-sensitive.

Gate 12 then demonstrates that the biological fine serial order is mostly just
ordinary monotonic taper, which is why the project moves toward branch
junctions and released NMDA dynamics rather than continuing to glorify matrix
order for its own sake.

## Closed status

Do not reopen Gates 0–11 to compete with the current front-page result.

Their job was to establish the language:

~~~text
history -> changing structure -> changing operator
matrix generator -> continuous motion
real arbor -> branching local-matrix scaffold
~~~

The current project begins where that language meets a real neuron and hard
causal nulls.
